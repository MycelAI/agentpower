# Contributing to Agentpower

Agentpower is an open framework. The goal is adoption, not ownership. Contributions that make the concept more precise, more measurable, and more useful are welcome.

## What We're Looking For

### Domain-Specific AP Benchmarks
The current definition of 1 AP is deliberately general. We need domain-specific baselines: what does 1 AP look like for a lawyer, an architect, a radiologist, an auditor, a teacher? Contributions that define measurable output baselines for specific professions would make the framework actionable.

### Case Studies
Real-world examples of teams or organisations that have measured their AP ratio, or data that allows it to be estimated. Anonymous is fine. Directional is fine. The Klarna example is public; we need more.

### Translations
The essay and definition in other languages. The term "agentpower" should remain untranslated (like "horsepower"), but the surrounding explanation benefits from native-language clarity.

### Critiques
Serious critiques of the framework's assumptions, limitations, or blind spots. The concept is a starting point. It should be stress-tested.

### Measurement Methodology
How should cognitive output actually be measured across different professions? This is the hard problem. Contributions from economists, organisational researchers, and practitioners are especially valuable.

## How to Contribute

1. Fork the repository
2. Create a branch (`feature/legal-ap-benchmark` or `critique/output-measurement`)
3. Submit a pull request with a clear description

For discussions and questions, open an issue.

## What We're Not Looking For

- Marketing content or promotional material
- Vendor-specific tool recommendations
- Content that frames AI as purely positive or purely negative (the essay deliberately holds both)

## Code of Conduct

Be constructive, be honest, be rigorous. The essay argues that the engine doesn't have a moral compass but the operator does. Same applies here.
